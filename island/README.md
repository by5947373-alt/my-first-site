# 23.5° 水上島

嘉義縣水上鄉的 3D 低多邊形微縮島嶼，獨立網站。
島嶼輪廓照水上鄉真實行政區界，八掌溪等河川和縱貫線也是真實路線（OpenStreetMap）。

## 視覺風格

療癒系生活模擬遊戲般的小鎮：圓潤的形狀、卡通分階光影（toon shading）、飽滿溫暖的顏色、
有一層層地層的蛋糕狀底座、點綴小花的草地。動態以「彈性」為主：開場時樹、房子、花從島中心往外一個個長出來，
建築依序「啵」地彈出、滑過會像果凍一樣抖、點擊會擠壓彈跳、待機時輕輕呼吸；
小居民是大頭小身體，走路一蹦一跳，點一下會開心地跳起來轉圈。介面按鈕按下去也會壓扁再彈回來。
（只取這類遊戲的整體氛圍，角色、美術與介面都是原創。）

## 功能

- **3D 島嶼**：旋轉、縮放、點建築或右側清單，鏡頭飛過去並打開介紹；建築會待機微動、滑過浮起、點擊彈跳。
- **時間**：清晨／白天／黃昏／夜晚的光線，預設一天會自己流動（約 5 分鐘一輪）；選了某個時段就停在那裡，再按一次恢復流動。夜裡窗戶和路燈會亮起。
- **工具列**：名牌（顯示／隱藏景點名稱）、搬運（在景點之間扛貨物來回的小人，點他看他在搬什麼）、
  連結線（景點之間的在地連結）、暫停（停住所有動態）、鳥瞰（正上方俯瞰）、日誌（探索日誌）、全螢幕。
- **景點索引**（右側；手機是底部抽屜）：搜尋、人文地產景分類、編號清單、景點介紹與「在地連結」，
  以及「連結」與「小旅行」分頁。
- **角色測驗**：「你是水上的哪一種旅人？」五個問題，依結果直接排好一趟小旅行。
- **小旅行**：加入景點、調整順序、顯示路線、自動導覽。
- **探索日誌**：記錄去過哪些景點、各分類收集進度。
- **海洋與小島**：主島四周是會流動的海，沿岸有白浪；附近有燈塔、漁港、沙灘、花海、觀星五座小島和一塊海鳥岩，
  帆船繞島航行、海鷗盤旋（裝飾用的想像場景，水上鄉本身不靠海）。
- **我的角色**（右上「角色」）：
  - 外觀：名字、身分（套用一組預設衣著）、髮型、髮色、膚色、眼睛、嘴巴、臉部配件、衣著、帽子、包包、手上拿的東西、身高與身形；
    可以隨機、重設，選擇面向鏡頭或背面，換一個站的地點（或直接點海上的小島），帶吉祥物「仙草仔」一起。
  - 行程：讓角色沿著小旅行一站一站走過去，鏡頭跟著走。
  - 拍照：選構圖（全身特寫／與島合照／從上面拍）和動作（揮手、比 YA、跳起來、轉圈），拍成拍立得照片下載。
  - 角色存在瀏覽器裡，下次打開還在。
- **新手導覽**：第一次打開會出現三步說明，右上角「?」可以再看一次。

小旅行、探索日誌、看過導覽與否都存在瀏覽器裡（localStorage）。

線上網址：https://by5947373-alt.github.io/my-first-site/island/

## 跑起來

```bash
npm install
npm run dev        # 開發模式，邊改邊看
npm run build      # 輸出 dist/，整個資料夾放到任何靜態主機就能用
npm run preview    # 在本機預覽 dist/
```

技術：React + TypeScript + Three.js + React Three Fiber + Drei，動畫用 `useFrame` 與 GSAP。

## 要改內容改哪裡

| 檔案 | 內容 |
|---|---|
| `src/data.ts` | 景點清單（`DEFS`）：名稱、人文地產景分類、3D 模型、**真實經緯度** `ll`、介紹與聯絡資訊；機場與車站（`DECOR`）；道路示意路線；在地連結（`LINKS`）；角色測驗（`QUIZ`、`PERSONAS`） |
| `src/spots.json` | 部分店家的地址、電話、營業時間（`DEFS` 用 `match` 對應） |
| `src/scene/Lighting.tsx` | 一天的光線、天空顏色、夜晚的路燈 |
| `src/scene/Links.tsx` | 連結線與搬運小人 |
| `src/avatar.ts` | 角色外觀選項、身分預設、附近小島 |
| `src/Character.tsx` | 角色面板（外觀／行程／拍照、拍立得照片） |
| `src/scene/Avatar.tsx` | 角色本體、姿勢、走行程、吉祥物仙草仔 |
| `src/scene/Ocean.tsx` | 海洋、白浪、小島、帆船、海鷗 |
| `src/scene/Folk.tsx` | 小居民（大頭、蹦跳走路、被點到會跳起來） |
| `src/scene/kit.tsx` | 共用形狀、卡通材質、微風與開場長出來的著色器 |
| `src/scene/models.tsx` | 各景點模型與專屬動畫（北回歸線光束、糖廠煙囪、咖啡蒸氣、行星旋轉、夜市燈串…） |
| `src/scene/Landmarks.tsx` | 建築互動：待機微動、滑過浮起、點擊彈跳、選中光圈、標籤避讓 |
| `src/scene/CameraRig.tsx` | 正交等角鏡頭、鏡頭飛行、平移限制 |
| `src/world.ts` | 農田、樹、房子、丘陵的擺放（固定亂數種子，每次長得一樣） |
| `src/App.tsx`、`src/styles.css` | 介面：工具列、景點索引、介紹、小旅行、測驗、日誌、新手導覽 |
| `src/geo.json` | 鄉界、河川、鐵路幾何，由 `npm run geo` 從 `osm/ring.json`、`osm/lines.json` 產生 |

景點依真實經緯度擺放（和鄉界、河川同一個投影）。市區店家彼此距離很近，島上會把建築稍微推開，
所以市區的位置是「相對位置」而非精確門牌。標註「位置示意」的地點只知道村落或路段：
綠色隧道、九芎埤、大智慧農場、木瓜、蓮子、林家古蹟；水上夜市、水上市場、金成藥鋪的位置也是依路段推估。

**待確認的內容**：上面標「位置示意」的地點；烘焙旅程、雨豆樹、廣東烤鴨的座標沿用原本資料，沒有再次查證；
「林家古蹟」目前對應十一指厝的林家三合院（水上沒有正式指定的林家古蹟）；
「在地連結」是示意的在地故事。位置、介紹與連結內容請依實際情況在 `src/data.ts` 修改。
道路是串連景點的示意路線，不是真實路網。

## 效能

樹、房子、農田都用 InstancedMesh；樹和作物的搖擺在頂點著色器裡算；
畫面掉格時自動降低解析度；按「暫停」或系統設定減少動態（`prefers-reduced-motion`）時停止環境動畫。
