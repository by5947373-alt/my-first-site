# 🧾 發票自動整理

用手機拍發票或收據 → Claude AI 讀出上面的文字 → 存進你的 Google 試算表，每個月一張工作表（`2026-10`、`2026-11`…）。

支援：電子發票、傳統發票（二聯式／三聯式）、計程車收據、高鐵票、其他收據。

## 功能

- **手機操作**：網頁做成手機大小，可以「加入主畫面」當 App 用
- **拍照／從相簿上傳**：照片自動縮小後存到 Google 雲端硬碟 `發票照片/YYYY-MM/`
- **AI 讀文字**：Claude 讀照片，自動填好 票據類型、日期（民國年會轉西元）、金額、發票號碼、統編、店家、品項、類別；
  高鐵的起訖站與車次、計程車車號等放進備註。填好後先讓你核對再存。
- **QR 碼雙重確認**：電子發票如果也讀到 QR 碼，號碼、日期、金額以 QR 碼為準（比讀字更可靠）
- 沒設定 AI 金鑰時，只會讀電子發票 QR 碼，其他請手動填
- **自動查店名**：沒填店家名稱時，用統編到經濟部商工登記資料查公司名稱
- **依月份分工作表**：依「發票日期」放進對應月份的工作表，沒有就自動建立（含標題列），最新月份排最左邊
- **防重複**：同一個月份已經有相同發票號碼會提醒
- **月合計**：頁面上看得到每個月的張數與總金額

試算表欄位：

| 上傳時間 | 發票日期 | 發票號碼 | 賣方統編 | 賣方名稱 | 銷售額(未稅) | 稅額 | 總金額 | 類別 | 品項 | 備註 | 照片 | 來源 | 票據類型 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

## 安裝（約 5 分鐘，只需要做一次）

### 1. 建立 Apps Script

1. 打開（或新建）你要存發票的 Google 試算表
2. 上方選單 **擴充功能 → Apps Script**
3. 把 `Code.gs` 內容全部換成 [`apps-script/Code.gs`](apps-script/Code.gs)
4. 左邊「檔案」旁按 **＋ → HTML**，檔名打 `index`，內容貼上 [`index.html`](index.html)
5. 按 💾 儲存

> 想存到別的試算表：把試算表網址 `/d/` 和 `/edit` 中間那串填進 `Code.gs` 最上面的 `SPREADSHEET_ID`。

### 2. 產生通行碼

1. 上方函式選單選 **setup**，按 **執行**
2. 第一次會要求授權（試算表、雲端硬碟、外部連線）→ 選你的帳號 → 進階 → 前往（不安全）→ 允許
   （這是你自己寫的程式，Google 對沒審核過的程式都會這樣提示）
3. 下方「執行紀錄」會出現 **通行碼**，記下來

### 3. 設定 Claude API 金鑰（AI 讀文字）

1. 到 https://console.anthropic.com 註冊／登入 → **Billing** 儲值（最低 5 美元）
2. **API Keys → Create Key**，複製 `sk-ant-` 開頭的金鑰
3. 回 Apps Script，左邊 ⚙️ **專案設定** → 最下面 **指令碼屬性** → **新增指令碼屬性**
   - 屬性：`ANTHROPIC_API_KEY`
   - 值：剛剛的金鑰
4. 按 **儲存指令碼屬性**

費用：每張約 0.02–0.03 美元（約新台幣 1 元）。想更省可以把 `Code.gs` 的 `AI_MODEL` 改成 `claude-haiku-5-5`（便宜很多，但準確度較低）。
金鑰只存在你的 Apps Script 裡，手機和網頁都看不到。

### 4. 部署成網頁

1. 右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**
2. 執行身分：**我**；誰可以存取：**所有人**
3. 按部署，複製「網頁應用程式網址」（結尾是 `/exec`）

### 5. 手機開啟

- **最簡單**：手機直接打開剛剛的 `/exec` 網址，輸入通行碼就能用。
  用瀏覽器的「分享 → 加入主畫面」，以後點圖示就開。
- **或用自己的網站**：本專案的伺服器在 `/invoice/` 也提供同一個頁面，第一次打開時填入 `/exec` 網址與通行碼即可。

設定只會存在這支手機上，換手機要重新輸入。

## 常見問題

- **已經部署過，更新程式後要重新部署**（見下一條），否則手機上還是舊版。
- **改了程式沒生效？** Apps Script 要 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不變。
- **通行碼外流了？** 在 Apps Script 執行 `resetToken`，執行紀錄會出現新的通行碼，舊的立即失效。
- **QR 碼讀不到？** 靠近一點、讓左邊的 QR 碼清楚對焦、避免反光再拍一次。讀不到也可以直接手動輸入。
- **類別想改？** 改 `index.html` 裡的 `CATEGORIES`。
